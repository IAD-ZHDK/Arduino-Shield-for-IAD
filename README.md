# Arduino-Shield-for-IAD

A simple prototyping shield with Lynx Smart Servo and qwiic/stema connectors for both Ardiuino UNO and MKR board shapes.  

The arduino UNO shield uses pins uses the following pins for software serial to the LYNX smart servo connector:

rxPin 8
txPin 9

The MKR shield uses the following pins for hardware serial the LYNX smart servo connector on SAMD21 devices: 

rxPin 1
txPin 0
