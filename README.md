# Arduino-Shield-for-IAD

A simple prototyping shield with Lynx Smart Servo and qwiic/stema connectors for both Ardiuino UNO and MKR board shapes.  

MKR                                                      |  UNO 
:-------------------------------------------------------:|:--------------------------------------------------------:
![Image of MKR PCB](/RAW/MKR.png?raw=true) | ![Image of UNO PCB](/RAW/UNO.png?raw=true)  





The arduino UNO shield uses the following pins for software serial to the LYNX smart servo connector:

rxPin 8

txPin 9

The MKR shield uses the following pins for hardware serial (SAMD21 devices) the LYNX smart servo connector: 

rxPin 1

txPin 0
